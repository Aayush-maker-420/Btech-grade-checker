# Btech-grade-checker
Python project

## About
This is my first Python project. It checks a percentage and displays a grade.

## Features
- Checks percentage from 0 to 100
- Displays a grade using conditional statements
- Handles invalid input

## Technology Used
- Python
- Functions
- If-elif-else statements
- Input validation

## How to Run
1. Install Python.
2. Download the Python file.
3. Open it in Python IDLE.
4. Run the program and enter a percentage.
